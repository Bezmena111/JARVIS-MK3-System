# JARVIS MK3

Jednoduchý, ale rozšírený projekt s:
- holografickou klávesnicou
- bezpečnostným panelom
- offline AI príkazmi
- WebAuthn biometriou
- scan/audit funkciami
- systémovými stavmi a logom

## Spustenie

Stačí otvoriť `index.html` v prehliadači.
